# Dewy Churn Prevention

일반 SaaS 와 Dewy 의 churn 구조가 근본적으로 다릅니다. **결혼이라는 이벤트 자체가 자연스러운 이탈 시점** 이므로, churn 을 "넌 왜 떠나는거···" 으로 접근하면 실패.

Dewy 의 churn = **"담임 권한 이미 다했다"** 를 인정하고, 그 다음 세계로 자연스럽게 안내하는 공정.

---

## 1. Dewy churn 지표 포인트

| 지점 | 이탈 속성 | 우선 액션 |
|---|---|---|
| Day 1—7 (설치 직후) | "이게 내 앱 아닄" | `onboarding` 강화 |
| 구독 1차 결제 실패 | 의도는 있었던 이탈 | 결제 재도·대체 수단 |
| 구독 2차 자동결제 실패 | 카드 만료 / 잔고 부족 | 결제 재도 + 결제 수단 업데이트 요청 |
| 구독 해지 버튼 클릭 | 명시적 이탈 의사 | save offer |
| **예식일 D+1 이후** | 가치 수명 종료 인식 | **신혼부부 모드 전환 제안 — 핵심** |
| 예식일 D+30 이후 | "이제 쓸 일 없을 듯" | 신혼가전·이사 콘텐츠 |
| 30일 미접속 | 조용한 이탈 | 재활성화 카퍼니 (아래 테마 술) |

→ **예식일 관련 이탈이 다른 모든 이탈 합계보다 클 가능성 높음**. 일반 SaaS 의 "월별 균등 이탈" 프레임으로 접근하면 잘못됨.

## 2. 구조적 대응 전략

### 전략 A: "예식일 후 모드" 자동 전환

예식일 D+1 자동으로 **신혼부부 모드** 제안:
- "결혼 축하드려요! 이제 듀이는 두 분이 신혼생활을 시작하시는 데 함께할게요."
- 이후 콘텐츠: 신혼가전 구매 순서, 이사 체크리스트, 신혼집 인테리어, 활동병합 / 하니문 머니 정리, 언제면 아기·임신/친가 행사 관리
- "결혼 업체 자료" 은 숨기고 "결혼 이후 필요 자료"가 앞으로

### 전략 B: 결제 실패 복구 (Dunning)

KakaoPay 구독 자동결제 실패 시:
- 실패 즉시: 알림톡 + 푸시 + 이메일 (3채널)
- 메시지: 입장 차분하게. "결제가 안 되세요. 서비스는 7일간 그대로 쓰실 수 있어요."
- 결제 수단 업데이트 원탭 제공 (아이디 티켓 아닌)
- 7일 후 해지 처리 (즉시·자동 해지 금지)

### 전략 C: 해지 클릭 시 Save Offer

한국 시장 주의점: 지나친 입장·명백한 다크 패턴 = 업계 시구 하항. 운영도 조심하게:

1. **이유 물을 때 다제다 했을거레 표정**:
   - "예식 끝났어요" → 신혼부부 모드 제안
   - "너무 비싸요" → 하트 개별 구매로 전환 제안
   - "안 써요" → "잠시 멈춤(pause) 1개월" 제안
   - "기능이 부족해요" → 구체적 피드백 수집 후 즉시 해지
2. **해지는 항상 1클릭 안으로 완료 가능**. 제안은 *머물러면* 제공, 점원 안는 안아도 됨.
3. **해지 단계에서도 환불 정책 명시** — "몇 일 이용하셔서 자동 정산 환불 N 원".

### 전략 D: 30일 미접속 재활성화

이메일 + 카카오톡 1:1 (알림톡 아닌 채널 대화창 초대):
- 테마 1: "결혼 준비, 잘 되어가세요?" — 1인칭 공감
- 테마 2: "너무 몀 몇 주 동안 찾아주셨던 분이 없으세요" + 새로 추가된 기능 1개만
- 제한: 30일, 60일, 90일 — 3회만. 이상 = 스팸

## 3. "한국 시장 구독 해지 원칙"

- 언제든 앵 클릭으로 해지 가능해야 (전자상거래법)
- 자동갱신 앞롬 7일 전 알림 의무 (KakaoPay 구독 규정)
- 해지 후 잘아있는 구독 일수는 그대로 사용 가능 (즉시 서비스 중단 금지)
- 7일 내 미사용 증명 되면 전액 환불
- 하트 충전은 7일 내 미사용 환불 (전자상거래법 "디지털 콘텐츠 미이용")

이 원칙을 수동결제 필요 없도록 **UI 에 장착**. 다크 패턴 = 공정거래위원회 제재 이슈.

## 4. 세그먼트별 churn 프로파일

| 세그먼트 | churn 주 원인 | 우선 액션 |
|---|---|---|
| 설치 1일 이내 미활성화 | "내 앱 아닄" | onboarding 강화 |
| AI 1회만 쓰고 떠난 유저 | 첫 답변 좋은 경험 못함 | AI 프롬프트 품질 개선 + Day 5 추가 프롬프트 메시지 |
| Premium 1개월 해지 | 가치 자각 안 됨 | 구독 기간 "활용한 기능 N개 · 절약 금액 N원" 요약 제공 |
| Premium 6개월 이상 유저 | 예식일 임박 → 이탈 위험 증가 | 예식 일주일 전 "마지막 점검" 캘리지 + 결혼 후 모드 예고 |
| 결혼 후 30일 이상 접속 | 가치 종료 | 자동 신혼부부 모드, 신혼가전·이사 콘텐츠 |

---

## 5. 시그널: 이탈 이전 경고

- AI 플래너 사용 빈도 50% 낙 (주간 비교)
- 알림 클릭률 전주 대비 70% 낮음
- 하트 구매 이후 30일 내 구매 안 함
- 결제 수단 만료 30일 전

이 시그널이 울릴 때 **이탈 앞서 먼저 개입** (양방향 메시지, 설문 등).

---

## 6. 안티패턴

- ❌ 해지 버튼 숨김 / 편의도 고의적 저하. 공정거래위원회 점검 위험.
- ❌ "해지하면 N개월간 활용 데이터가 사라져요" 압박. **데이터는 계정 탈퇴 전에는 유지**.
- ❌ "절대 가지 마세요!" 점원식 의령 만류. 논리적 근거 + 동의 잘 되어야 재구독 가속.
- ❌ retention 눌리기 위해 고객 지원 접근성 낮춤. 한국 시장 주은 이슈.
- ❌ 예식 직후 대량 churn 을 "우리 탓이 아니니까" 취급. 신혼부부 모드·신혼 콘텐츠로 LTV 2—3배 가능.
