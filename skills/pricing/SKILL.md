# Dewy Pricing

설계 이전에 **현재 구조를 먼저 외울 것**. 가격·할인율 젔대 임의 변경 금지.

---

## 1. 현재 가격 구조 (정본)

### 하트 충전 (Toss Payments)

| 패키지 | 가격 | 하트 | 단가 |
|---|---|---|---|
| 스타터 (최조 1회) | 1,900원 | 10 | 190원 |
| 기본 | 4,900원 | (heartPackages.ts 기준) | |
| 스마트 | 9,900원 | | |
| 가성비 | 19,900원 | | |
| 대용량 | 49,900원 | | |

**권장 소스 오브 트루스**: `src/lib/heartPackages.ts` (Dewy repo). 각 패키지 구체 하트 수·보너스 하트 구성은 그 파일에서 확인.

**기능별 하트 소비**:
- AI 드레스 시연 — 5 하트
- AI 메이크업 시연 — 5 하트
- 모바일·종이 청첩장 — 2 하트
- 웨딩 촬영 시안 — 3 하트
- 식전 영상 외주 — 정액제 (별도)

### Premium 구독 (Kakao Pay)

| 주기 | 가격 | 단가 환산 | 할인 |
|---|---|---|---|
| 월간 | 4,900원 | 4,900원/월 | — |
| 연간 | 39,000원 | 3,250원/월 | 33% |

**혁택**: AI 플래너 무제한 + PDF 견적 리포트 무제한.

### 가입 보너스

- 신규 가입 포인트 `signup_bonus` 자동 적립
- 정확 금액은 소스 코드 확인

### B2B

- 업체 등록·갤러리·문의 관리
- 요금제는 현재 협의 형 (공개 정찰표 미확정)

## 2. 가격 결정 원칙 (Dewy)

1. **했단 단가 완전 투명** — "스타터는 하트 1개 = 190원"의 계산 과정을 고객이 머릿속으로 할 수 있도록.
2. **다음 패키지는 단가 감소** — 4,900 → 9,900 → 19,900 으로 가면 단가가 떨어져야. "큰 게 이득" 명확해야 신뢰.
3. **Premium 은 "한 달에 X건 이상" anchor 으로** — 하트 누적 사용 5건 이상이면 Premium 이 이득. 이 계산을 앞에 내세우.
4. **연간 할인은 33% 고정** — 임의로 변경 금지.
5. **환불 정책 명시** — 구독 해지는 언제든지, 하트는 구매 후 7일 내 미사용 시 환불 (전자상거래법).
6. **축소판 (downgrade) 경로 개방** — Premium → 하트 전환을 해지보다 먼저 제안.

---

## 3. 가격 테스트 제안 시 고려사항

- 가격 인상 = **기존 구독자 그랜드퍼드링**. 한국 시장 신뢰 손상 큰 이슈.
- 가격 인하 도 신중 — 결정이 단윽 단임. 한 번은 "프로모션" 으로, 재행 시에는 "가격 추세" 로 인식.
- A/B 테스트는 segment 로 **신규 유저만 대상**. 기존 유저 가격 파동 금지.
- 결제 수단 다양성: KakaoPay + 신용카드 이외에 Apple Pay/Naver Pay 추가 검토.

## 4. 가격 푐 (제품 페이지)

권장 틀:

```
[세 칼럼]  무료  |  Premium  |  B2B (별도 문의)

머릿줄: 가격 + 주기
  무료: 0원
  Premium: 월 4,900원 (연 39,000원 = 33% 할인)
  B2B: 업체 당 협의

핵심 차이:
  무료 — AI 플래너 일 5회, 기본 플래닝 도구 전부 포함
  Premium — AI 플래너 무제한, PDF 리포트 무제한

하트는 별도 안내 (패키지별 그리드)
```

- "인기" 표시는 Premium 에만 (일반적 관행)
- B2B 는 "자세히 알아보기 → 문의" 흐름으로

## 5. 경쟁사 가격 참조

직접 애플리케이션 비교 금지 (가치 축이 다름). 대신:
- **서울 프린트업체 수수료 대비**: 최소 50만원+ vs Premium 연 39,000원
- **웨딩 캴설팅 1회 대면 상담**: 30만원~ vs AI 플래너 무제한 월 4,900원
- **일부 업체 아틀레틀 5만원~ vs 하트 스타터 1,900원**

한국 시장은 "개인 결정 비용 vs 총 결혼 비용 수억원" 간격 건드릴 때 구독률 급증. 이 연결 필수.

## 6. 안티패턴

- ❌ "한정 수량 남았어요" 가짜 시급성. 한국 시장 이제 감지 빠름.
- ❌ "가격 곧 오릅니다" — 계획 없으면 쓰지 말 것. 모돈일이잔트도 끊임.
- ❌ 구독 해지 경로를 찾기 어렵게. 권리보호 심의 대상.
- ❌ 자동결제 전환 앞롬 공지 없이. KakaoPay 구독 규정 위반 + 언팔로우 이슈.
- ❌ 하트 만료 이후 환불 거부. 애초에 소멸 조건 명시.
- ❌ B2B 증가세 / 현금영수증 처리 누락. 세무·회계 리스크.

## 7. 프로모션 서택

- 첫 구매(스타터) 이외의 "첫 구독 N% 할인" 은 광고·CRM 캠페인으로서면 가능, 공개 가격표에는 미노출
- 추천인 코드 (referrals 스킬) = 서로 하트 X개 증정 권장 (현금 할인 · 구독금 할인보다 관리 쉬운 차원)
- 시장 이벤트 (결혼 시즌 완화기 프로모션)은 시안하되, 기존 구독자 제외 조건 명시
