## 1. Dewy 용 조사 유형

| 유형 | 쓸 때 | 명원 | 소요 |
|---|---|---|---|
| **논 스톱퍼 인터뷰** | 행동 "왜" 파고자 할 때 | 5—8명 | 30분/명 |
| **D-Day 구간별 설문** | 행동 "어떻게" 수치 잡을 때 | 100명+ | 5분 |

## 2. 설문 설계 (Dewy 전용 테플릿)

### 스크리닝 질문 (자격 필터)
- 결혼 예정일 (D-Day) — 필수
- 공식 예비신랑/신부/신혼부부/결혼 준비 보조자(부모·친구) — 타겟마다 언어·질문 다르게

### 핵심 질문 6개

1. **고민 최근 월** — "이번 달 결혼 준비 하면서 가장 스트레스 받은 일 하나" (자유 서술, 필수)
2. **입장·어흄** — "그 일 때문에 어떤 결정을 더 알아볼 수 있으면 했을까요?"
3. **현재 도구** — "다음 에서 최근 1개월 안에 쓴 것 다 고르기": 웨딩북 / 네이버 카페 / 구글 검색 / 컬때·엑셀 / 양가 조언 / 카카오 채팅 / 파트너와 구두 / Dewy / 기타
4. **의사결정 구조** — "가장 큰 지출 항목 결정은 주로 누가요?": 나 / 파트너 / 둘이 함께 / 양가 부모
5. **돈 출처** — "결혼 비용 주로 어디서 나오나요?" 자신·저축 / 부모 지원 / 대출 / 기타
6. **돈 내고도 쓸 개선점** — "다음 중 월 5,000원 내고 쓸 의향 있는 것": (서비스 기능 5개 제시, 여러개 선택 가능)

**질문 7개 이상 금지** — 완성률 급락.

### 설문 채널
- 앱 안 in-app 설문 (이탈자가 아닌 잠재 이탈자 · 일부 샘플링)
- 프리미엄 유저: 필수 조사 그룹으로 관리
- 추첨: 하트 5개 증정 + 답변 소개 (소액 + 의미 있게)

## 3. 논 인터뷰 가이드 (Dewy)

### 30분 세션 구조

1. **아이스브레이커 (3분)** — "자연스러운 대화, 접대하는 게 아니에요. 틀린 답은 없습니다."
2. **결혼 준비 여정 되짚어보기 (10분)** — "언제 결혼을 결정하셨어요?" → "그 이후 첫 액션은?"  → "그 다음에는?" — *행동* 을 따라감
3. **JTBD 질문 (10분)** — "이때 X를 쓰어보셨는데 어떨어요?", "그게 도움 되셨나요?", "어떤 부분이 아쉬웠어요?"
4. **Dewy 관점 (5분)** — "만약 이런 기능이 있다면 쓰셨을 것 같아요?" 곳곳에 "왜요?" × 3
5. **마무리 (2분)** — "제가 여쪽분께 안 물어봤는데 꼭 알아주셨으면 하는 게 있으세요?"

### 금지
- "이 기능 쓰실 의향 있으세요?" — 가설적 질문에 이용자는 "네" 한다. 실제 행동 에서 검증.
- "우리 앱이 좀 어떤 거 같아요?" — 자기 제품 자랑 금지.
- 5분 안에 "그래서 특징이 이거잖아요···" 서술 금지. 이용자가 80% 말하도록.

## 4. JTBD Four Forces 매핑 (Dewy)

인터뷰 결과를 아래 표에 채우세요. **`.agents/product-marketing.md` 의 Switching Dynamics 섹션 업데이트 소재**.

| Force | 인터뷰에서 쯤은 verbatim | Dewy 을 대입한 관점 |
|---|---|---|
| Push | "컬때가 파트너한테 공유 안 되서···" | 의사결정 파워 보고 있음 |
| Pull | "파트너랑 같은 예산 화면 보면 좋을 것 같아요" | 커플 동시 사용 anchor |
| Habit | "네이버 카페가 편해요" | 정보·클레임 컴텍스트 |
| Anxiety | "앱 설치 더 하기 귀착8아요" | install friction |

4 개 다 종이에 쓰지 말고 *가장 강한 1개를 높이고 가장 큰 마찰 1개를 낮추는* 액션으로 연결.
