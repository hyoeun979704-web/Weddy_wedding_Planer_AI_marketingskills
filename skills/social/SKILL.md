# Dewy 소셜 미디어

**`.agents/product-marketing.md` 의 Customer Language** 가 모든 소셜 컨텐츠의 톤 기준.

---

## 1. 채널 매트릭스 (한국 결혼 시장)

| 채널 | 컨텐츠 타입 | 톤 | 빈도 | 목적 |
|---|---|---|---|---|
| **Instagram** | 릴스(AI 드레스 Before/After), 캐러셀(체크리스트), 스토리(설문·투표) | 시각, 짧고 강한 카피 | 주 3—4회 | 발견 + 사회적 증명 |
| **Naver 블로그** | 장문 가이드("D-180 결혼준비 체크리스트"), 도시별 시리즈 | 정보·신뢰, 존댓말 | 주 1—2회 | SEO 유입 |
| **YouTube Shorts** | 30~60초 (스드메 견적 후기, 드레스 시연 결과, 결혼준비 꿀팁) | 짧고 임팩트, 자막 큼 | 주 2—3회 | 발견 + 신뢰 |
| **KakaoStory** | 짧은 텍스트 + 이미지 (이벤트, 신규 기능 공지) | 친근체 가능 | 주 1—2회 | retention |
| **카카오톡 채널** | 알림톡, 친구 추가 시 혜택 안내 | 직접 안내 톤 | 이벤트 시 | retention + 재방문 |
| Threads / TikTok | 실험 단계 | — | 분기 1—2회 시도 | 실험 |
| LinkedIn / Twitter | B2B (웨딩 업체 마케터) 만 | 정보 톤 | 월 1—2회 | B2B 인지 |

## 2. 컨텐츠 기둥 (Content Pillars)

5개 기둥에서 70/20/10 룰로 분배:

| 기둥 | 비중 | 예시 |
|---|---|---|
| **결혼준비 꿀팁** (정보 + 가치) | 40% | "D-180 이 시점에 꼭 해야 할 5가지" |
| **AI 데모·기능 자랑** (Dewy 차별점) | 20% | AI 드레스 시연 Before/After 릴스 |
| **고객 후기·페르소나 공감** (사회적 증명) | 20% | "D-90 인 수지님의 결혼준비 일주일" |
| **업계 인사이트·트렌드** (권위) | 10% | "2026 한국 웨딩 트렌드 5가지" |
| **이벤트·프로모션** (전환) | 10% | "이번 주 신규 가입자 한정" |

70/20/10 = 가치 70%, 회사 자랑 20%, 직접 판매 10%. 직접 판매 비중 넘으면 언팔로우 증가.

## 3. 채널별 포맷 가이드

### Instagram 릴스 (15—30초)

**구조**:
- 0~2초: Hook ("드레스 5개 발품 팔다 지쳤어요?")
- 3~20초: Demo (AI 드레스 시연 화면 녹화)
- 21~30초: CTA ("무료로 한 번 입혀보기, 프로필 링크")

**자막 필수** — 한국 모바일 사용자 80% 무음 시청.

### Naver 블로그

**구조**:
- 제목 50자 내 ("서울 D-180 결혼준비 체크리스트 — 우리는 이렇게 했어요")
- 도입 3~5줄: 페르소나 공감 ("수지님처럼 D-180 이신가요?")
- 본문 H2 3~5개
- 결론: Dewy 자연스러운 멘션 (직접 판매 아님)
- 이미지 5장 이상 (Naver SEO 가중치)

**장문**: 1,500~2,500자. 짧은 글은 검색 노출 낮음.

### YouTube Shorts

**제목**: "D-180에 꼭 해야 할 5가지" 식 숫자 + 시기 + 작업
**썸네일**: 강한 대비, 짧은 캡션, 사람 얼굴 (가능하면) — 한국 시장은 사람 표정 중요

### KakaoStory

**구조**:
- 짧은 문장 (40—60자) + 이미지 1—2장
- 친근체 가능 ("이번 주 신규 기능 나왔어요!")
- 카카오톡 채널로 유도

### 카카오톡 채널 (알림톡)

**구조**:
- 친구 추가 즉시 메시지: "안녕하세요, 듀이예요. D-Day 입력하면 우리만의 결혼준비 로드맵 만들어 드릴게요."
- 정기 발송 절대 금지 (스팸 신고 → 카카오 채널 정지 위험). **이벤트·중요 안내만**.

## 4. 캘린더 추천 (`references/korean-wedding-market.md` 섹션 9 와 연동)

| 월 | 우선 주제 |
|---|---|
| 1—2월 | 설 직후 "양가 자리에서 결혼 이야기 나왔다면" 페르소나 |
| 3—4월 | 봄 결혼 시즌 직전 — 마지막 점검 컨텐츠 |
| 5월 | 가정의 달 — 부모님 페르소나 |
| 6—8월 | 여름 = 비수기, 가을 결혼 D-90 컨텐츠 |
| 9—10월 | 가을 성수기 — 실시간 결혼 후기 컬래보 |
| 11—12월 | 내년 봄 결혼 D-180 — 식장 예약 컨텐츠 |

## 5. 성과 측정

채널별 단일 핵심 지표:
- **Instagram**: 저장 수 (좋아요·도달보다 의미 큼)
- **Naver 블로그**: 검색 유입수 + 이웃 추가
- **YouTube Shorts**: 평균 시청 지속 시간
- **KakaoStory**: 댓글·공유 수
- **카카오톡 채널**: 친구 수 증감, 알림톡 클릭률

Vanity metric (팔로워 수 자체) 금지. **앱 설치·가입 인입수** 가 결국 evidence.

## 6. 안티패턴

- ❌ 한 컨텐츠를 모든 채널에 그대로 복붙. 채널마다 톤·길이·포맷 다 다름.
- ❌ "수만 명이 선택" 같은 검증 안 된 통계.
- ❌ 인플루언서 광고를 자체 컨텐츠처럼 위장 (한국 광고 규정 위반).
- ❌ DM 으로 일방 영업. 한국 시장 거부감 강함.
- ❌ 카카오톡 채널에서 정기 푸시. 채널 친구 손실 1순위.
- ❌ 결혼 식·날짜 모르는 사람의 결혼사진 무단 사용. 초상권 분쟁 위험.
