# 한국 결혼 시장 도메인 지식

Dewy 스킬을 쓸 때 참조할 한국 웨딩 시장의 고유 용어·관행·평균 비용·경쟁사 정리.

---

## 1. 핵심 용어

| 용어 | 설명 | 관련 키워드 |
|---|---|---|
| 스드메 | 스튜디오 + 드레스 + 메이크업 (한국 웨딩 패키지 기본 3세트) | 스드메 추천, 스드메 검색, 스드메 패키지 |
| 셋폐악 | 스드메 적구대 (세 업체가 함께 판매하는 프로모션 패키지) | 셋폐악 견적, 셋폐악 웨딩 |
| 결혼정보업 (웨딩컨설팅) | 스드메·식장 계약 도와주고 수수료 받는 업체 | 결혼정보업체, 웨딩컨설팅 |
| 프린트업체 | 고객은 수수료 안 내고 업체가 핏박 결제 시 수수료 받는 형태 — "고객은 공짜"이라 마케팅하지만 프맀엄 업체 올린 가격 포함 가능성 명시 | 프린트업체 후기 |
| 예단 | 신부가 시당에 보내는 현금·예물 | 예단 시마, 예단 가격, 예단 생략 |
| 함 | 양가 사이 주고받는 예물 모음 (경아이 서널, 최근 접은 트렌드) | 함 후기 |
| 상견례 | 양가 철 결혼 의사 확인하는 공식 자리 | 상견례 일정, 상견례 차림 |
| 보증인원 | 식장 계약 시 최소 하객수 | 보증인원 추세 |
| 폐백 | 식장 단독 관리 (1 식장 = 1 예식) | 폐백 식장, 폐백 이상 |
| 경교이식 | 식장이 2–3 시간 내 다른 식 춘롤 | 경교이식 파트, 경교이식 장단점 |
| 식대 | 하객 식사명당 비용 (평균 6–10만원) | 식대 조정, 식대 보증 |
| 속애 | 신랑·신부 각자의 친가 친구·친조 하객 | 속애 명단 |
| 샘웨딩 (스몰웨딩) | 속애 / 가족 중심 소규모 (대객 30–60명) | 스몫웨딩 장소, 스모앨웨딩 비용 |
| 셀프웨딩 | 업체 안 끼고 커플이 직접 기획 (제주도 / 해외 웨딩 포함) | 셀프웨딩 준비 |
| 하우스웨딩 | 외국 일부 지역 인기 — 양가적이지 않은 스타일 | 하우스웨딩 입장료 |
| 식전영상 | 식장 입장 전 상영하는 커플 소개 영상 (한국 특히 일반적) | 식전영상 제작, 식전영상 가격 |
| 청첩장 | 종이 + 모바일 청첩장 둘 다 쓰는 게 관행 | 모바일청첩장 제작, 청첩장 서식 |
| 신부대기실 | 하자관 이용 접수 자리 (신랑은 입구 좌석, 신부는 대기실) | 신부대기실 팔지, 신부대기실 꾸미기 |
| 골든타임 | "이 시점에 해야" 하는 권장 시기 (D-365 / D-180 / D-90 등) | 웨딩 골든타임, 스드메 골든타임 |

## 2. 평균 비용 (2025년 기준, 수도권)

| 항목 | 가격대 | 비고 |
|---|---|---|
| 예식 전체 (스드메 + 식장 + 예단 + 신혼여행) | 1.2–2억원 | 메탈저축례근 기준 |
| 식장 (200명 점심/주말) | 2,500만 – 6,000만원 | 식대 포함 |
| 스드메 패키지 | 250만 – 800만원 | 스튜디오 장소·드레스 등급별 |
| 예단 | 100만 – 500만원 | 최근 감소 추세 |
| 신혼여행 | 500만 – 2,500만원 | 국가·기간별 |
| 신혼가전 · 신혼집 가구 | 1,000만원– | 시애 활용 쪽 더 절약 |

→ 광고/카피에 일반화 수치 쓸 때 이 범위 클 초과 금지.

## 3. D-Day 기준 골든타임 (Dewy 스쾀줄 테플릿)

| 단계 | 주요 액션 |
|---|---|
| D-365 ~ D-270 (12–9개월 전) | 식장 투어 · 예약, 예산 총량 설정, 양가 일정 협의 |
| D-270 ~ D-180 (9–6개월 전) | 스드메 계약, 신혼여행 국가 결정 |
| D-180 ~ D-90 (6–3개월 전) | 예단·함, 신혼가전·식기·침구, 철 근, 철 애·철 애 피팅 |
| D-90 ~ D-60 (3개월—2개월 전) | 청첩장 디자인, 속애 명단 정리, 신부대기실 콘셉 |
| D-60 ~ D-30 (2개월—1개월 전) | 청첩장 발송, 헬스·다이어트, 리허설 일정 조율 |
| D-30 ~ D-Day | 아이템 리스트, 디테일 점검, 총 예산 재점검 |
| D+0 ~ D+30 | 식후 정산, 신혼여행, 이사·상견사진 출력 |
| D+30 ~ | 신혼부부 모드 — 가전·가구, 활동병합·하니문 머숴, 이사 후속 관리 |

→ 캠페인·이메일·푸시는 가입일이 아니라 **예식일 D-N** 기준으로 설계. churn-prevention 은 D+30 이후에 입장 필수.

## 4. 주요 경쟁사

| 서비스 | 타입 | 강점 | 약점 (Dewy 기회) |
|---|---|---|---|
| **웨딩북** | 통합 앱 | 업체 등록 수 압도적, MAU 최대 | AI 부재, 업체 광고 공감 피로, 커플 공유 약함 |
| **레딩레딩** | 체크리스트 특화 | 디자인, 관리의 재미 | AI·추천 없음, 정보조회 분리됨 |
| **웨딩플래너** | 혈레더 | 일정 관리 단순 명료 | 커플 동기화 약함, AI 없음 |
| **예비맘** | 네이버 카페 | 흐적, 관계성 | 신뢰도·고잔 광고, 관리 부재, 개인화 불가 |
| **웨딩계 / 드레스계 블로그** | 인플루언서 | 실제 후기·설득력 | 추천 편향·광고 획솨, 도구 검색·일정·예산 없음 |
| **카카오톡 오픈채팅 결혼정보업** | 1:1 수동 제안 | 대면 장점, 고가 패키지 판매 높음 | 파트너 동기화·디지털 도구 없음, 수수료 의존 |
| **The Knot / Zola** | 글로벌 | 대규모 데이터베이스 | 한국 도메인 없음 — 경쟁사 아닌 수준 |

→ 경쟁 렌즈: **AI 개인화 + 커플 동시 사용 + 사진 시연** — 경쟁사 아무도 이 3각형 없음.

| 우선순위 | 채널 | 이유 |
|---|---|---|
| 1 | **Naver 검색 광고 + 파워링크 / 블로그** | "웨딩북", "결혼준비 앱", "스드메 추천" 검색 의도가 명확. 한국은 Naver 가 서치 다수 |
| 2 | **Kakao Moment + 카카오 비즈니스 채널** | 예비 신부 일상 소비·관심사에 대한 달타겟팅 우수 |

| 4 | **YouTube Shorts — 30초 스킨 투어 + 고민 해소 영상** | "스드메 견적 좌충우돌" 같은 내러티브 |
| 5 | **네이버 블로그 SEO** | 신부·신랑의 장문 콘텐츠 탐색 이후 이탈 적다 |
| 6 | **Google 검색 / Google Play 스토어 (ASO)** | Android 출시 주력 채널 |
| 7 | **메타/Facebook 광고** | 이미지 소재, retargeting |
| 8 | **커뮤니티** — 맘이뜨, 웨딩카페, 결론·옷럄·디시인사이더 태그 | 공유 유도 |
| (후순위) | LinkedIn / Twitter(X) / TikTok | 한국 웨딩 시장 접점 낮음 |

## 6. 광고 소재 제작 시 주의점

- 결혼 그 자체를 바꿔주겠다는 과장 금지 ("결혼 준비 시간 90% 단축" 안됨 — 출처 없음)
- 시아부모·고부 등 부정적 키워드 사용 금지 (광고 심사 거절 사유)
- "결혼은 일생에 한 번"과 같은 압박 표현 신중하게 (재혼·동성 커플 소외 표현 주의)
- 하트·구독 가격은 정확하게 (코드 소스는 `src/lib/heartPackages.ts`)
- AI 가 "완벽"이라고 극찬 금지 — "도와드립니다", "권고드립니다" 수준이 적절
- 사진 처리 설명: 30일 자동 삭제 명시

## 7. Naver SEO 키워드 시아드

메인 커텍섬터:

- 웨딩북 / 결혼준비 앱 / 결혼준비 체크리스트 / 결혼 준비 절차 / 스드메 추천 / 프린트업체 후기

롱 테일 퓨널:

- "결혼준비 6개월·서울·예산 5000만 / 스드메 우양·동대문 비교 / 고림장 vs 알레그리아 평균 견적"
- 한국은 구체적 수치·지역·시기 조합에서 검색 높음 → programmatic SEO 기회

## 8. 어팔·톤 결정 귀칙

| 면 | 톤 |
|---|---|
| 랜딩 페이지 헤드라인 | 존댓말, 짧고, 감정 쪽소용 (예: "결혼 준비, 이제 편하세요.") |
| 앱 내 UI 버튼/메뉴 | 명사·동사구, 검존댓말 · 명령조 피해서 시작하기 / 따라가기 식 |
| 푸시 알림 | 간결체 + 친근체 (이모티콘 1개 허용: 예 💛) |
| 이메일 뉴스레터 | 편지 톤 ("안녕하세요, 수지 님. 이번 주 준비 고민은 뭴가요?") |
| AI 답변 | 존댓말 고정, 끝에 개인화 한 줄 ("수지님 예식일 기준으로 말씀드렸어요.") |
| 계약·결제 화면 | 완전한 존댓말, 금액·조건 겹쳐 수치 모호하게 쓰지 않음 |

## 9. 캠페인 일자 추천 (한국 웨딩 계절성)

| 시기 | 테마 | 채널 |
|---|---|---|
| 설 / 추석 직후 | "명절에 양가 자리에서 결혼 준비 이야기 나왔다면" | Naver/Meta |
| 3—4월 (봄 시점) | 모니터 시단이 돌아온 곳도 많은 대표 성수기 | 종합 |
| 5월 가정의 달 | 부모 페르소나 — "따님/아들 결혼 준비 자넹해주고 싶을 때" | 부모 관점 콘텐츠 |
| 9—10월 가을 성수기 | 올해 결혼·이년 봄 결혼 둘 다 | 이벤트 |
| 11—12월 | 내년 식장 예약 적섬기 (서울 신구 입동) | 프로모션 |

이 문서는 Dewy 서비스 컨텍스트 + 한국 웨딩 시장 메타 정보를 해석하는 레퍼런스. 스킬 자체는 *간결하고 구체적*으로 유지하고, 구체 레퍼런스는 이 문서와 `.agents/product-marketing.md` 에 집중.
